## Допустимые статусы задач

- `inbox` — входящие, ещё не разобрано.

## Правило для AI Operator

Когда нужно создать новую задачу из входящего контекста:

1. Если проект очевиден — создать задачу в `tasks` со статусом `inbox` и заполненным `project_id`.
2. Если проект неочевиден — создать задачу в `inbox` без проекта и явно указать, что проект нужно определить.
3. Не выдумывать проект.
4. Не менять статусы существующих задач без отдельного основания и безопасного audit trail.
5. Не удалять и не отменять задачи без явного подтверждения Андрея.
